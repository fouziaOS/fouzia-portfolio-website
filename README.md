# Fouzia Hoque — Personal Data Science Portfolio Website

A personal portfolio website for **Fouzia Hoque**, CSE student at Southeast University and aspiring Data Scientist.

## Sections
- **Home** — hero with typing animation and key stats
- **About Me** — background, FYDP research, and skills
- **Python Projects** — FocusFlow Study Planner, QuizMaster Python Quiz, KharchaTrack Expense Tracker, Bellman-Ford/Yen-BF poster
- **NumPy (50 Codes)** — the NumPy in 50 Examples collection
- **Data Visualization (50 Codes)** — Matplotlib gallery with 6 featured charts (all 50 on GitHub)
- **Data Analysis** — FYDP survey analysis (pilot, N = 100) and the 5-step analysis workflow
- **GitHub Profile** — @fouziaOS with links to all repositories
- **Contact** — email, GitHub, location, university

## How to view
Just open `index.html` in any browser — it works fully offline, no server or internet needed (GitHub links need internet, of course).

## Files
- `index.html` — page structure and content
- `style.css` — dark data-science theme, responsive layout
- `script.js` — typing animation, scroll reveal, mobile menu
- `images/` — 6 chart images from the Data Visualization project
